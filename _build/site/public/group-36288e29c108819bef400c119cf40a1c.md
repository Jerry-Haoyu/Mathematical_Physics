## Groups and Subgroups 
### Some fun bu incorrect analogies
A group $G$ is an algebra structure that is closed. To this aspect, a group is like a biological species. When two individual mate and produce an offspring, we would expect it is still of the same species.There are also subspecies. For instance consider dogs as a "group". Two labradors would give birth to another labrador. 
   
Likewise, in groups, mating is defined by a binary operation(binary means takes two inputs) $\cdot : G\times G\to G$. It takes parents $g_1,g_2\in G$ as input and returns the offspring $g_3$. There are also subgroups which describes similar subspecies situation where we can find a subset of elements that is also closed.

This analogy is good as long as we  only consider the closedness aspect. A group is fundamentally different(well, firstly the binary operation is deterministic while breeding is probablistic and they only produce one output while you can have multiple offsprings). Also, group posses more strucutre known :

1. There eixsts an identity  $e$ which perserves every element $g\in G$  through the binary operation. 
2. There exists an inverse for every element. Identity is recovered when an element is put through the operation with its inverse. 
3. The binary operation is associative, it doesn't matter which element .
   
These requirements are known as the *group axioms*. A useful mental picture:

:::{figure} media/group_inverse.png
Every element has an inverse where they produce the idenity through the binary operation $\cdot$
:::

A natural question about the number of elements a group posses(called the *order* of agroup) would arise seeing this picture. Does this mean groups are always odd ordered? Interestingly no because although the inverse is unique and the identity is unique(both can be easily derived from the group axioms), an element can be its own inverse. A quick example:

:::{prf:example}
Consider the group $\mathbb{Z}_2=\{[0]_2, [1]_2\}$ where $[0],[1]$ are the congruent classes. The binary operation is $+$ for congruent classes. The identity is $[0]_2$. Note $[1]_2$ is the inverse of itself: $[1]_2+[1]_2=[0]_2$
:::

Hence finite-ordered groups can have both odd and even odrder. Formally:


:::{prf:definition} Groups
A group is a tuple $(G,\cdot)$ of a set $G$ equipped with a binary operation $\cdot$ such that they satisfy the **group axiom**:
1. There exists an identity $e$: $\forall g\in G$ $$ eg=ge=g$$
2. Every element has an inverse: $\forall g\in G, \exists g^{-1} $ such that $$gg^{-1}=g^{-1}ge$$
3. $+$ satisfies associativity:$\forall g_1,g_2,g_3\in G$ $$ (g_1g_2)g_3=g_1(g_2g_3)$$
:::

If all elements of the group are commutative with respect to each other, then the group is called **abelian**.

### Additive group of integers modulo $n$
:::{prf:definition} $\mathbb{Z}_n$
This is the group with elements $\{[0]_n,...,[n-1]_n\}$ being the congruence class modulo $n$. The binary operation is addition between congruence classes which can be proven to be well-definied. 
:::
- The identity is $[0]_n$
- Inverse of $[k]_n$ is $[n-k]_n$
- Associativity inheirted from associativity of integer addition
